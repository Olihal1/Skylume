> [!IMPORTANT]
> SkyLume is closed-source software. This repository contains support files only; the mod source code is not published here.

## Get help

Choose the form that best matches your situation:

| I want to... | Use this form |
| --- | --- |
| Report a reproducible problem | [Bug report](https://github.com/Olihal1/Skylume/issues/new?template=bug_report.yml) |
| Report Minecraft closing or crashing | [Crash report](https://github.com/Olihal1/Skylume/issues/new?template=crash_report.yml) |
| Suggest an improvement | [Feature request](https://github.com/Olihal1/Skylume/issues/new?template=feature_request.yml) |
| Ask a setup or usage question | [Support request](https://github.com/Olihal1/Skylume/issues/new?template=support_request.yml) |

You can also [open the issue chooser](https://github.com/Olihal1/Skylume/issues/new/choose) or [search existing issues](https://github.com/Olihal1/Skylume/issues).

## Before submitting

1. Update to the latest official SkyLume release available for your Minecraft version.
2. Search open and closed issues for the same problem or suggestion.
3. Choose the correct form and complete every required field.
4. For bugs, include exact reproduction steps, expected behavior, and actual behavior.
5. Attach screenshots and `latest.log` when relevant. A crash report must include the crash report or `latest.log`.

Official releases are distributed only through [SkyLume on Modrinth](https://modrinth.com/mod/skylume).

## What happens after submitting?

Your report becomes a public GitHub issue. You can follow it to receive notifications when questions, status updates, or a fix are posted. Please answer follow-up questions in the same issue so all diagnostic information stays together.

An issue may be closed when it is fixed, cannot be reproduced, duplicates an existing report, concerns an unsupported version, or is caused by another mod or local configuration. Closing an issue does not delete the discussion.

## Privacy

GitHub issues and uploaded files are public. Before posting, remove:

- Minecraft session tokens
- API keys or authentication data
- Private server addresses
- Personal information
- Any other secret or sensitive value

Usernames and mod lists may be useful for diagnosis, but only share information you are comfortable making public.

## Repository scope

This repository is intentionally limited to:

- Support requests
- Bug and crash reports
- Feature requests
- Public status discussions for submitted reports

It does not contain SkyLume's source code or development builds.
